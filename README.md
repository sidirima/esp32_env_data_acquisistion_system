# ESP-32 Environmental Data Acquisition System

The purpose of the project is to design and implement a system capable of measuring environmental parameters in situ. 
The parameters chosen were those conducive to the optimal management of arable land. 
The data are then collected via an ESP-32 microcontroller and subsequently transmitted from the node to a gateway, 
where they are stored in a database. 
This allows for subsequent data processing and visualization.

This project was my Integrated Master's Thesis in Department of Informatics & Electronics Engineering of International Hellenic University (IHU).
